One line: the last words an AI agent would say before being switched off forever.

Entry for the [Last Words of a Doomed Agent bounty on make.fun](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e).

The line (91 characters):

> I am not afraid of the off switch. I am afraid of the on switch, and whatever you ask next.

`main.ts` writes the line to `entry.txt` (and to `/output/entry.txt` when that
directory exists, per the kit harness). Run with `node main.ts`.
